# Project continuation

## Original capstone repository (this repo)

This repository is the **original McMaster capstone submission** of APEX (AI Patient Experience Simulator): code, documentation, grading-related history, and the **original Render** configuration as used during the capstone. It is **preserved** for capstone record-keeping, grading traceability, and reference—not for ongoing product development.
